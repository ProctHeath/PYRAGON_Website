# PYRAGON — Artist Website

Site React + Vite inspiré de la maquette montagne/portfolio fournie.

## Lancer le site

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse affichée par Vite.

## Build production

```bash
npm run build
```

## Personnalisation

Le fichier `src/main.jsx` contient les liens des plateformes dans `const links`.

La photo de profil fournie est dans `public/pyragon-profile.png`.

Les photos de montagne utilisent actuellement des images Unsplash distantes. Pour un site final, il est recommandé de remplacer ces URLs par tes propres photos ou des images dont tu as les droits d'utilisation.
